# TASK-022 Internal Playtest Protocol

Obtain explicit versioned consent before collection. Target at least eight
participants; label any smaller sample directional. Randomize the same Gray Harbor
seed between causal summary and compact chronological fallback, include advice
rejection/partial follow and a complete no-push path, and use three declared
offline intervals.

Record only assignment, summary/inbox view, causal-link view, bounded answer code,
usefulness/clarity/pressure/anxiety/fiction-framing ratings, and explicit return
intention. Do not store free text, clickstream, DOM, IP, user agent, or cross-site
identifier. Report missing data and bootstrap confidence intervals.

Predeclared expansion gates: deterministic privacy/provenance/copy gates all pass;
median causal comprehension at least 80%; no severe coercive/emergency rating;
majority explanation cites knowledge/personality/goal/relationship evidence; and
continued-interest improvement beats the chronological condition by 10 percentage
points. Human judgments cannot override hard gates.
